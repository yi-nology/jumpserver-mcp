# pkg/ —— 这一面没有通用库

**⚠️ 这一层是空的，而且它是故意空的。**

通用库（协议层、门禁、结果整形、留痕、脱敏、失败分类、契约守卫的机械）住在
**另一个仓**：`github.com/yi-nology/jumpserver-mcp-kit`。

`⚠️ **为什么它们不住在本仓**：本仓是**一个服务**。通用库是「**两个服务都认
的东西**」—— 只被一个服务够得到的包，是那个服务的私有代码披着共享的名字
（另一个服务迟早会伸手进去，两个服务就在**没有人决定过**的情况下耦上了）。`

`⚠️ **为什么不许在本仓的 pkg/ 里放东西**：放进去的第一个包会变成「只有这一
面够得到的包」，而它住在叫 `pkg/` 的目录里 ⇒ 下一个读代码的人会以为它是
共用的。要放，就放进 kit。`

## 这一面的对应物

这一面**有**对应物的地方是 `internal/repository/`（堡垒机的资源）、`internal/service/`（领域规则）、`biz/handler/`（工具）—— 各自的目录名就说清了它们是什么。
