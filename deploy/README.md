# deploy/ —— 部署

**⚠️ 这一层是空的，而且它是故意空的。**

这一面交付的是**一个二进制**（stdio 上的 MCP server），它跑在 MCP 客户端那台
机器上，而不是跑在集群里 ⇒ 没有编排文件、没有镜像、没有 Helm chart。

`⚠️ 什么时候它不再是空的：如果这一面开始以容器形态交付，就在这里放
Dockerfile 与部署清单。

`⚠️ **只放一处**：发版产物是 GitHub Release 里的六个平台二进制 ⇒ 镜像必须
是**同一份**产物，不是另编一次（另编一次的那个，版本对不上，而版本对不上
这件事只有读 --version 的人才发现得了）。`
