# etc/ —— 配置

**⚠️ 这一层是空的，而且它是故意空的。**

这一面的配置是**环境变量**驱动的，装载代码在 `internal/config/`。⇒ 这里
没有 yaml。

`⚠️ 什么时候它不再是空的：如果配置要能从**文件**读（部署环境里把配置挂进
来，而不是一个个环境变量），那就在这里放 `config-<env>.yaml`，并让
`internal/config` 读它。

`⚠️ **但只有一份**：环境变量与 yaml 两套并排，就是两套要保持同步的东西
—— 而「哪一份说了算」这件事没有人会记得去查。`
